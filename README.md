# asset-pack-template

Template for asset packs of Moorhuhn Kart: Open Source Edition. Set the id, title, description and author in pack.json, replace icon.png and put your files into Assets/ at the same paths as the game's files, for example Assets/mhk2/Music/mhk2_title.ogg. Every push to main publishes the pack as a GitHub release, and the game installs it from the repository link.
